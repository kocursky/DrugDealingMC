# DrugDealingMC
It's the drug dealing Minecraft Server to download and play with friends, inspired by schedule I! 

## Dostępne drugi:

Grzyby
Metamfetamina


## Jak pobrać (każdy system)?

Pobierz "Source code".zip poniżej
Utwórz folder
Przenieś pobrany plik (Source Code) do tego folderu
Kliknij prawym na pobrany plik, i znajdź opcję wypakuj/wyodrębnij.
Jeżeli nie widzisz opcji wypakuj/wyodrębnij pobierz program [7-zip](https://www.7-zip.org/).

## Jak uruchomić serwer (Windows)?

Jeżeli nie masz, pobierz Oracle Java 25, [TUTAJ](https://adoptium.net/temurin/releases?version=25&os=any&arch=any)
Pobierz start.bat poniżej
Wrzuć go do środka folderu
Uruchom start.bat

## Jak uruchomić serwer (Linux)?

Jeżeli nie masz, pobierz Oracle Java 25, [TUTAJ](https://adoptium.net/temurin/releases?version=25&os=any&arch=any)
Pobierz start.sh poniżej
Wrzuć go do środka folderu
Otwórz terminal w folderze
Wykonaj polecenie './start.sh'
